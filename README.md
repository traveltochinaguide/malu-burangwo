# 马路不让我上班

60 秒通勤躲避网页小游戏：8:55 出发、9:00 打卡，躲避鬼探头大爷、横穿行人 / 电动车、逆行电动车、外卖小哥、开门杀、龟速汽车。结算自动生成「今日迟到原因」战绩卡，可复制、可保存 900×1200 图片发小红书。

- 在线玩：https://malu-burangwo.pages.dev/
- 单文件 `index.html`（three.js + Polyfork 免费资产 CDN，加载失败自动用程序替身）
- 本地运行：`python3 -m http.server 8000`，打开 http://localhost:8000
- 红线：无血腥、无撞人演出，结算附“现实中请减速礼让”
